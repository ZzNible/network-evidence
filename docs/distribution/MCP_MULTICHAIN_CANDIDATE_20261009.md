Optional OP Stack finality additionally allows only finalized/safe/latest head reads, the exact subject height, and bounded parentHash links. Pinned Solana origins allow only getGenesisHash, transaction, signature status and block. Per-method params are prevalidated, no redirects, arbitrary headers or submission.
- Source/acquisition normalization and **all network verdicts** come from native `@nec/resolver-evm`, `@nec/resolver-solana` and `@nec/core` validators (including the reviewed H1-H5 security fixes integrated below). The MCP wrapper adds only bounded transport metadata, with `artifactType=network-evidence-fragment` and the exact Core artifact; **it never creates a full `NetworkEvidenceResult`** when evidence policy/preflight/context is missing.
- Shared process-local 8 successful admission slots per minute / 2 concurrent acquisitions across BOTH families; inner EVM adapter also has its own 8/min guard. Response bounds: Base 128 KB per RPC, Solana 800 KB per RPC, whole MCP AFTER envelope (including any optional adapter-local claim assessment) 450 KB; per RPC time limits Base 6 seconds, Solana 8 seconds. Public rollout also needs global quota controls when scaling past one instance, provider rate-limit confirmation, Cloud Run billing protections and adversarial review.
- Every request is a **single** source observation, not an independent cryptographic proof or network consensus. No Core confidence score. EVM inclusion/receipt ≠ OP Stack L2 finality or withdrawal finalization. Solana source-reported `finalized` ≠ cryptographic verification or x402 settlement. A pruned/null response is unavailable/insufficient evidence, not a contradiction of existence.

## Opt-in OP Stack L2 block finality (same AFTER MCP tool, NOT DEPLOYED)

- Optional request flag includeL2Finality=true is accepted ONLY for the fixed Base mainnet and Base Sepolia profiles. No extra sixth MCP tool, no new chain, no Core or resolver mutation. Default no-flag behavior is unchanged; Solana with this flag is rejected BEFORE outbound reads. The caller may also supply the existing independently assessed native protocol claim; protocol agreement, execution and L2 finality are not conflated.
- On a coherent native EVM receipt-to-block anchor, the original OP Stack resolver independently collects one RPC source identity, finalized/safe/latest heads, each required parentHash link, exact-height canonical block and a finalized-head stability re-read when the ancestry walk completed. It emits an independent, Core-validated finality-ONLY NetworkEvidenceFragment alongside the unchanged generic EVM execution/effects/dataBinding fragment. No full NetworkEvidenceResult is fabricated from two partial fragments.
- The explicit Base OP Stack family profile and native ruleset opstack.rpc-finalized-head-v1 control the evaluation; they are not guessed from numeric chain IDs. The wrapper only allows the three named block-head tags, the exact subject-block height and strict parentHash reads, all from pinned origins with bounded bytes/time. Each capture exposes method, bounded request parameters, digest/status and acquisition timestamp; raw untrusted RPC response bodies do not enter the MCP output.
- Resource ceiling: 8 ancestor hashes; at most 14 additional read-only RPC requests per opt-in beyond the generic EVM acquisition (4 reads), with an explicit counter inside the scoped fetch. Older blocks may thus get finality INSUFFICIENT even though their height lies well below the source finalized head. INSUFFICIENT has different native causes: ancestry beyond budget, source finalized head below the subject, or unavailable facts. Inspect warnings/reasons; do not infer universally finalized or unfinalized. No universal N-confirmations rule.
- Exact transaction anchor unavailable: toolStatus=not_evaluated, no extra OP Stack reads. OP Stack provider read failure: toolStatus=source_unavailable, generic execution fragment preserved. Source/config/validator internal contract defects are NOT mislabeled provider outages; they fail closed as internal errors. Non-evaluated/unavailable modes cannot carry a finality fragment or captures.
- Regardless of verdict: withdrawalFinalization=not_evaluated; ethereumSettlement=not_evaluated. L2 finalized head evidence is SOURCE OBSERVATION by one RPC only, NOT independent L1 derivation, full consensus or economic irreversibility; neither withdrawal finalization nor protocol payment settlement follows.
